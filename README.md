# RazDwaSzybko.pl

Nowoczesna platforma cyfrowa łącząca zleceniodawców z wykonawcami usług – szybko, bezpiecznie i bez zbędnych formalności.

## 🚀 O projekcie

**RazDwaSzybko** to aplikacja webowa stworzona z myślą o osobach, które cenią swój czas i szukają sprawdzonych rozwiązań w codziennych zadaniach. Platforma ułatwia proces zamawiania oraz realizacji usług w jednym miejscu.

---

## 🛠️ Technologie

Projekt został zbudowany przy użyciu nowoczesnego stosu technologicznego:
* **Frontend:** Next.js (React), Tailwind CSS, Lucide Icons
* **Backend & Baza danych:** Supabase (Auth, PostgreSQL, Realtime)
* **Płatności i powiadomienia:** Resend, system transakcyjny z obsługą kodów promocyjnych
